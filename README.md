# Landscape Studio

조경 설계 웹 프로그램 (2D 평면 + 3D).

## 파일
| 파일 | 내용 | 업데이트 때 |
|---|---|---|
| `index.html` | 프로그램 본체 | 새 버전으로 교체 |
| `firebase-config.js` | Firebase 연결 설정 | **바꾸지 않음** |
| `firestore.rules` | 데이터 접근 규칙(참고용 사본) | 팀원 추가 시 Firebase 콘솔에서 수정 |

## 접속
GitHub Pages 주소: `https://jeongwooha8-tech.github.io/landscape-studio/`

1. Google 계정 로그인 (firestore.rules 에 등록된 이메일만 통과)
2. 프로그램 안의 사용자 선택 또는 관리자 로그인
